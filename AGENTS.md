# Work on this source repository

Read instructions.txt before configuring an installation. Treat this repository as
independent source, not a connection to its creator's running service.

Keep owner credentials and trading authority separate from analysis and agent access.
Every boot must remain DISARMED. Do not enable host brokerage writes, ARM, place test
orders, deploy paid resources, or publish secrets as part of installation/testing.
Do not modify the trading strategy while performing distribution or isolation work.

Run synthetic engineering tests with outbound sockets blocked. Do not import private
state, historical records, credential caches or deployment metadata. Scan staged files
and Git objects before publication. Never solve an isolation failure by weakening auth.
